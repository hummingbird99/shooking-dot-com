# 쇼핑몰 연동 리뷰

## 고객사 요구사항
### 상세 페이지
- 상품 이미지, 가격, 설명을 상품 페이지의 리스트와 동일하게 구현해주세요.
- 장바구니에 담는 버튼과 수량을 늘리고 줄일 수 있는 버튼을 만들어 주세요.
- 관련 상품 추천 리스트가 화면 하단에 노출되게 해주세요.

### 결제 완료 페이지
- 사용자가 총 결제 금액을 확인할 수 있고, 상품 목록 보기 버튼을 눌러 상품 페이지로 이동이 가능하게 만들어 주세요.

### 전체 페이지 연동
- 페이지 간 이동 시 데이터들이 일관성을 유지하도록 구현해주세요.

## 요구사항에 따른 기능 동작 확인

✅ 상세 페이지
<br>
✔️ 상품 이미지, 가격, 설명이 상품 페이지 리스트와 동일하게 표시되는지 확인
<br>
✔️ 장바구니 담기 버튼이 정상적으로 동작하는지 테스트
<br>
✔️ 수량 증가/감소 버튼이 정상적으로 동작하며, 최소 1개 이상 유지되는지 확인
<br>
✔️ 관련 상품 추천 리스트가 화면 하단에 정상적으로 노출되는지 확인
<br>

✅ 결제 완료 페이지
<br>
✔️ 사용자가 총 결제 금액을 정확하게 확인할 수 있는지 테스트
<br>
✔️ 상품 목록 보기 버튼을 눌렀을 때 상품 페이지로 정상 이동하는지 확인
<br>

✅ 전체 페이지 연동
<br>
✔️ 페이지 간 이동 시 상품 정보(이미지, 가격, 설명 등)가 일관성 있게 유지되는지 확인
<br>
✔️ 장바구니에 담긴 상품 정보가 다른 페이지에서도 유지되는지 확인
<br>
✔️ 결제 완료 후 장바구니 데이터가 정상적으로 초기화되는지 테스트
<br>
✔️ 브라우저 새로고침 후에도 데이터가 일관성을 유지하는지 확인
